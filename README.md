### Victor Fagundes

Engenheiro de Software (UTFPR). SQL e PL/SQL no dia a dia; construo agentes com LLM.

**Projetos**

- **[orcamento-bot](https://github.com/VictorFagund/orcamento-bot)**: o prestador de serviço manda um áudio e recebe um orçamento em PDF com Pix. A IA real foi avaliada em 38 frases (36 certas, nenhum preço inventado); 195 testes.
- **[vagas-agente](https://github.com/VictorFagund/vagas-agente)**: agente que lê vagas de 3 fontes, descarta por regra e embedding antes de chamar o LLM. 3.102 vagas lidas, só o topo vai para o modelo, custo zero. Um fluxo no n8n roda todo dia e avisa as novas no Telegram.
- **[vale-o-desvio](https://github.com/VictorFagund/vale-o-desvio)**: qual posto compensa de verdade, contando a ida e volta. Só dados oficiais da ANP, 5 mil cidades. [No ar](https://victorfagund.github.io/vale-o-desvio/).

Todos são protótipos; cada README tem o status e os próximos passos.
